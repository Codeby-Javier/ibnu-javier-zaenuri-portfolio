## About this portfolio

This repository is the portfolio itself — a scroll-driven cinematic site with pinned typography, interactive About, a 3D project journey, and mouse-tracking Spline robots.

- **Plain HTML, CSS, JS** — no framework, no build step
- **Scrubbed scroll animation** — stops and reverses with your scroll
- **Light first paint** — heavy 3D assets hydrate on approach
- **Accessible** — `prefers-reduced-motion`, touch fallbacks, no-JS hero

```bash
python -m http.server 4173
# open http://localhost:4173
```
